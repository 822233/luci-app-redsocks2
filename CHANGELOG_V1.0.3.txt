Redsocks2 LuCI 1.0.3
====================

- Add selectable webpage connectivity targets and a custom HTTP/HTTPS URL.
- Measure webpage time to first byte separately from full download throughput.
- Verify HTTPS proxy certificates instead of disabling certificate checks.
- Add isolated ss-local based Shadowsocks webpage testing when ss-local is installed.
- Clean up temporary Shadowsocks processes, PID files and configuration after testing.
- Deduplicate subscription nodes by protocol, endpoint and credentials before import.
- Preserve the active node when it still exists; otherwise select the first newly imported node.
- Decode percent-encoded subscription credentials and validate supported Shadowsocks ciphers.
- Keep the previous subscription configuration if UCI cannot create replacement nodes.
- Register the local LuCI package in the ImmortalWrt SDK package tree and check shell syntax before compilation.

Compatibility note:
- IPv6 proxy endpoints remain excluded from subscription import because IPv6 support in the bundled Redsocks2 core has not been verified.
- Shadowsocks webpage testing requires a compatible ss-local executable; it is optional and is not a hard package dependency.
